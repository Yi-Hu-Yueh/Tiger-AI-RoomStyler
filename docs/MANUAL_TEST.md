# Phase 1A-R 屋主人工驗證

目前狀態：**PASS**。第一次真實驗證曾收到不完整的 NVIDIA 回應；調高輸出預算並精簡輸出契約後，屋主已用真實房間照片完成 NVIDIA GLM-5.3-Flash 重測。分析成功，照片觀察基本正確，證據邊界框對齊正確，先前截斷問題確認已解決。

1. 在伺服器設定 `NVIDIA_API_KEY`，確認 `ROOMSTYLER_VISION_MODEL=z-ai/glm-5.3-flash`。依 README 啟動應用程式並開啟 <http://127.0.0.1:18083>（若埠已占用，改用空閒埠及對應網址）。金鑰已設定不代表連線或權限已驗證。
2. 上傳一張不敏感的真實室內房間照片。
3. 維持「允許購買」關閉。
4. 維持「允許移動大型家具」關閉。
5. 閱讀 NVIDIA 雲端告知、確認願意傳送照片與限制並接受可能的 API 費用後勾選同意，執行真實 NVIDIA NIM 分析。若圖片被拒、JSON 無效或輸出截斷，記錄錯誤；不得把模擬測試當作 API 成功證據。
6. 將每一項觀察逐一與照片核對。
7. 核對物品位置描述。
8. 若有框線，確認證據標註指向正確的可見物品或區域，並在縮放視窗後再次確認對齊。
9. 確認每項建議在現場都能實際執行。
10. 確認沒有建議要求購買物品。
11. 確認沒有建議要求移動大型家具。
12. 確認沒有建議修改牆壁、門、窗、配線、管線或房間結構。
13. 改變一項實際限制後再分析一次，確認新結果遵守變更後限制。
14. 上傳模糊、局部或非房間圖片，確認系統降低結論強度並揭露限制，而非虛構完整方案。
15. 記錄：錯誤觀察、幻覺物件、不切實際的目的地、沒有證據的假設、框線錯位，以及實際無法執行的建議。

屋主已提供必要的通過結果；Owner manual validation 與 Phase 1A 整體狀態均為 **PASS**。

請記錄測試日期、使用模型、每次限制快照、是否成功及具體錯誤；勿在紀錄中貼上 API 金鑰。官方 hosted 文件的圖片 schema 與模型指南仍存在落差，但本次真實 NVIDIA 分析已確認圖片可被模型理解。非阻斷注意事項：當「允許購買」關閉時，線材整理措辭可能隱含假設現場已有束帶、固定夾等材料；屋主執行前仍須確認現有材料，不應把該措辭解讀為購買授權。

8. 關閉「允許購買」重測：建議不得要求取得新的束帶、固定夾、盒子、收納用品或其他材料；若提及現有材料，必須同時提供不使用材料的替代方法。
